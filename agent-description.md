The idea is to introduce a third type of Joscity account called “Agent”, alongside the existing Personal and Business accounts.
In simple terms, Joscity Agents are trusted people who help other users buy things or deliver things on their behalf. Instead of a user having to personally search around Jos, contact several sellers, negotiate, arrange pickup and then find someone to deliver the item, they can simply open Joscity and hire an Agent to handle the process.
Joscity Agent System
When someone signs up on Joscity, the account options would eventually become:
Personal → Business → Agent
An Agent can offer one or both of two major services:
Help Me Buy (HMB) means: “I need something, but I want someone else to find it, buy it and get it to me.”
For example, a user may request:
“Help me buy an iPhone 15 Pro, fairly used, within ₦850,000.”

Joscity can then show suitable Agents who specialize in phones/gadgets, preferably Agents within the user's region. The customer can see each Agent's profile, location, rating, number of completed jobs and success history before choosing one.
Agents choose the categories they specialize in, such as electronics, phones and gadgets, fashion, groceries, automobile parts, building materials, furniture, etc.
Agents can also have their own product listings. This means an electronics Agent, for example, could display phones, laptops and accessories they already know how to source. Users could either select something from the Agent's listings or create a custom request.
Joscity could later introduce an AI Agent Search that automatically matches a customer's request with the most suitable available Agent based on category, location, rating, price and previous performance.
Help Me Deliver (HMD) is slightly different. Here, the customer already has an item somewhere and simply needs an Agent to pick it up and deliver it.
For example:
“Pick up a package from Terminus and deliver it to Rayfield.”

Available delivery Agents can accept the request, and the customer can see the Agent's information and live location while the delivery is taking place.
This effectively gives Joscity its own community-powered delivery network.
How payment would work
The system can have two wallets:
Normal Wallet — used for ordinary Joscity transactions, earnings, cashback and other services.
Escrow Wallet — used specifically to protect money during Agent transactions.
For example, if an Agent is helping someone buy a ₦100,000 television, the customer's money does not immediately go directly to the Agent.
The money is held securely by Joscity in escrow while the Agent performs the job.
The process becomes:
Customer requests item → Agent accepts → Customer funds escrow → Agent buys/sources item → Item is delivered → Customer confirms → Money is released to Agent.
This protects both sides. The Agent knows that the customer has actually provided the money, while the customer knows the Agent cannot simply take the payment without completing the transaction.
There should also be a dispute process if something goes wrong.
How Agents make money
Agents can add a service charge or percentage for doing the work.
For example:
Product price: ₦100,000
Agent service charge: 5%
Agent fee: ₦5,000
Delivery: ₦3,000  
Customer pays: ₦108,000
Joscity can place a maximum percentage an Agent is allowed to charge, preventing unreasonable charges while still allowing Agents to earn money.
Joscity itself can also take a small platform fee from successful transactions.
Trust and Agent reputation
Trust is extremely important for this feature, so every Agent should build a public reputation.
An Agent's profile could show things such as:
4.8 ★ rating · 126 successful purchases · 98% success rate · Electronics specialist · Currently in Jos North
After every transaction, customers can rate both the Agent and the item/service they received.
The system would therefore keep a permanent record of successful purchases and deliveries.
Agents could also have different levels or badges as their reputation increases.
For example:
New Agent → Verified Agent → Trusted Agent → Elite Agent
Certain privileges, such as larger withdrawals or handling high-value transactions, could require an Agent to reach a minimum reputation or transaction level first.
Regional Agents
Agents would operate based on location and region.
So if somebody in Rayfield requests groceries, Joscity should prioritize suitable Agents nearby instead of showing an Agent who is far away.
For some purchases, however, the Agent may be somewhere else. Someone in Jos could even ask an Agent in Lagos to source a particular product and have it delivered.
This starts turning Joscity into a person-to-person commerce network, rather than simply another online marketplace.
“Buy CBC and Save”
The CBC Card / CBC reward system mentioned in the concept can also be connected to Agent transactions.
Users could receive a small percentage of their spending as cashback/reward value when they use Joscity services.
For example:
Spend ₦20,000 through Help Me Buy → receive a percentage back in CBC rewards.

Those rewards could later be used for other services within the Joscity ecosystem.
The simplest way to explain the whole idea
Joscity Agents turns people in the city into trusted personal shoppers and delivery partners.
Instead of asking:
“Does anybody know where I can buy this?”

A user simply tells Joscity:
“Help me buy this.”

And instead of worrying about how an item will reach them, they can say:
“Help me deliver this.”

Joscity then connects them with a suitable verified Agent, protects the payment through escrow, allows them to track the transaction, and builds trust through ratings and transaction history.
So Joscity evolves from just having Personal users and Businesses into having a third economic participant:
Personal Users → Businesses → Agents
Businesses sell.
Personal users buy and use services.
Agents connect the two and physically get things done.
That makes the Agent layer potentially one of the most important parts of Joscity's smart-city digital economy, because it connects the digital marketplace on Joscity with real-world buying, sourcing and delivery.
